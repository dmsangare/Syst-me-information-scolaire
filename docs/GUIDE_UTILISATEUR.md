# SIS-MALI - Guide utilisateur

**Version :** 1.0
**Date :** 2026-10-31
**Public :** Personnel administratif et pedagogique

---

## 1. Introduction

SIS-MALI est un Systeme d'Information Scolaire pour les etablissements fondamentaux maliens (1ere a 9eme annee). Il permet de gerer :

- Les inscriptions et reinscriptions
- Les eleves et leurs familles
- Les classes et les matieres
- Les enseignants et leurs affectations
- Les emplois du temps
- Les presences et la discipline
- Les evaluations et les notes
- Les bulletins scolaires
- Les examens DEF
- Les finances (frais, paiements, depenses)
- Les documents administratifs
- Les rapports et statistiques
- Les sauvegardes et l'archivage

---

## 2. Connexion

### 2.1 Acceder a l'application

1. Ouvrir un navigateur web (Chrome, Firefox, Edge).
2. Saisir l'adresse : `http://[adresse-du-serveur]` (ou `http://localhost` en local).
3. La page de connexion s'affiche.

### 2.2 Se connecter

1. Saisir votre **email** ou **numero de telephone**.
2. Saisir votre **mot de passe**.
3. Cliquer sur **Se connecter**.

**Note :** a la premiere connexion, vous devrez changer votre mot de passe provisoire.

## 4. Utilisation quotidienne

### 4.1 Pour le secretaire

1. **Inscrire un eleve** : Menu > Eleves > Nouvel eleve.
2. **Reinscrire un eleve** : Menu > Eleves > selectionner l'eleve > Reinscrire.
3. **Affecter un eleve a une classe** : Menu > Inscriptions > Affecter.
4. **Generer un certificat** : Menu > Documents > Certificat de scolarite.

### 4.2 Pour l'enseignant

1. **Saisir les notes** : Menu > Evaluations > selectionner l'evaluation > Saisir les notes.
2. **Marquer les presences** : Menu > Presences > selectionner la classe > Marquer.
3. **Consulter les bulletins** : Menu > Bulletins > selectionner la classe.

### 4.3 Pour le directeur

1. **Valider les notes** : Menu > Evaluations > selectionner > Valider.
2. **Valider les bulletins** : Menu > Bulletins > selectionner > Valider.
3. **Prendre les decisions annuelles** : Menu > Decisions > Conseil de classe.

### 4.4 Pour le comptable

1. **Enregistrer un paiement** : Menu > Paiements > Nouveau paiement.
2. **Generer un recu** : Menu > Paiements > selectionner > Recu.
3. **Consulter les impayes** : Menu > Rapports > Impayes.

---

## 5. Problemes courants

### 5.1 Mot de passe oublie

Contacter l'administrateur pour reinitialiser votre mot de passe.

### 5.2 Acces refuse

Verifier que vous avez les permissions necessaires. Contacter votre superieur.

### 5.3 Erreur de saisie

Les notes validees ne peuvent plus etre modifiees directement. Contacter le directeur pour une correction.
